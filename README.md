# 綴り（つづり）— 小説執筆スタジオ

小説を書くことだけに特化した執筆アプリです。原稿（縦書きでも）・添削・設定資料・設定矛盾チェック・キャラ相関図・アイデア帳・プロット・空想地図（世界地図・国・旅の日数）・プレビュー・辞書・電子書籍（EPUB）や原稿用紙での書き出しを、作品ごとにひとつにまとめて管理できます。

- インストール不要。ブラウザだけで動きます（パソコン・スマートフォン対応）
- データはお使いの端末のブラウザ内に保存され、外部には送信されません（AI機能を使うときは本文が、辞書のネット検索では調べた言葉だけが送られます）
- 添削と設定矛盾チェックは、AIなしでもその場で自動的に行われます

## 使い始める

いちばん簡単なのは、1ファイル版を使う方法です。

1. [`dist/tsuzuri.html`](dist/tsuzuri.html) をダウンロードする
2. ダブルクリックしてブラウザ（Chrome・Edge・Safari・Firefox）で開く
3. 「サンプル作品を開く」で、各機能の動きを確認できます

そのほかの方法：

- **GitHub Pages で公開する**：リポジトリの Settings → Pages で公開するブランチ（例：`main`）を選ぶと、どの端末からでも URL で開けます（データは端末ごとに別々に保存されます）
- **手元のサーバーで動かす**：リポジトリ直下で `python3 -m http.server 8765` を実行し、`http://localhost:8765` を開く

> データはブラウザに保存されるため、ブラウザの閲覧データを消すと作品も消えます。右上の「↓」ボタンや「設定 → データ」から、定期的にバックアップ（.json）を書き出してください。

## できること

### 執筆
- 話（章）の追加・並べ替え（ドラッグ）・複製・削除
- 文字数（空白除く）、400字詰め原稿用紙換算、今日書いた文字数と1日の目標
- プレビュー（下の「プレビュー」を参照）
- 本文で語を選ぶと、下の欄の「調べる」からすぐ辞書を引けます
- ルビ `|漢字《かんじ》`、傍点 `《《強調》》`、「」『』……―― の入力ボタン
- 検索・置換（この話だけ／全話）
- 版の保存と履歴（大きく直す前に保存しておけば、いつでも戻せます。話の切り替え時にも自動保存）
- テキスト（.txt）での書き出し、**投稿サイト用の書き出し**（下を参照）
- **読み上げ**：カーソルの位置から（語を選べばその範囲だけ）声で読み上げ、読んでいる文に色が付きます。ルビは読みのとおりに読みます。速さ・声を選べ、書き始めると止まります（ブラウザの音声合成を使います）
- 統計：会話文の割合、漢字の割合、平均の文の長さ、読了目安、日ごとの執筆量
- **縦書きで書く**：ツールバーの「縦」のボタンで、本文を縦書きのまま書けます（添削の波線も縦書きの文字に付きます）。もう一度押すと横書きに戻ります
- **集中モード**：目のボタンで、本文だけを画面いっぱいに表示します（パソコンでは全画面）。書いている行がいつも画面の真ん中あたりに来る「タイプライター」表示つき。添削の波線は隠れ、Esc で戻ります
- **執筆スプリント**：下の「スプリント」から10〜60分を選ぶと、その時間に書いた字数を数えます。終わると音で知らせ、1時間あたりの字数とこれまでの最高を表示します（目標の字数も決められます）
- **版を比べる**：「版の保存と履歴」の「今と比べる」で、保存した版から書き直した所を、消した所（赤い取り消し線）と足した所（緑の下線）で表示します
- **テキストの取り込み**：ほかのアプリや投稿サイトで書いた .txt・.md の原稿を、話の一覧の「↑」やホームの「テキストを取り込む」から取り込めます。「第一話」「# 題」「プロローグ」などの見出しで話に分け、文字コード（UTF-8・Shift_JIS・UTF-16）も自動で判定します。pixiv のルビ `[[rb:漢字 > かんじ]]` や青空文庫の傍点も、綴りの書き方に直します
- **ごみ箱**：消した話・作品は30日間ごみ箱に残ります。消した直後の「元に戻す」、話の一覧の下の「ごみ箱」、ホームの「ごみ箱」から戻せます

### 添削（AIなし・自動）
本文を書くと、その場で次の点をチェックし、該当箇所に波線を引きます。指摘をクリックすると本文の該当箇所へ移動し、提案があればワンクリックで直せます。

| 分類 | 内容 |
| --- | --- |
| 誤字 | 「完壁」「絶対絶命」などのよくある誤字、「、、」「をを」などの重複 |
| 語法 | 慣用句の誤用（的を得る・汚名挽回など）、重言（頭痛が痛い・違和感を感じるなど）、ら抜き言葉、地の文のい抜き言葉 |
| 記号 | 括弧の閉じ忘れ、閉じ括弧前の句点（〜。」）、三点リーダー・ダッシュの作法、！？の後の全角スペース、半角カナ・半角記号 |
| 体裁 | 段落頭の字下げ（作品全体の書き方に合わせて判定） |
| 読みやすさ | 長すぎる文、読点の多い文、同じ文末の連続（〜た。〜た。〜た。）、接続詞の連続、「の」の連続、同じ語の近い繰り返し（地の文。人物名などは除く） |
| 表記 | 表記ゆれ（できる／出来る、子ども／子供 など約50語。作品全体で多い方に揃える提案）、設定資料の「表記統一ルール」 |
| ルビ | 空のルビ、同じ語でルビが揺れている（作品全体で多い方を提案）、「足《アルファ》」のような特殊な読み |

#### 特殊な読み（ルビ）は「読み方」に登録すると指摘しない
「足《アルファ》」のように、ふつうとは違う読みをわざと使う語は、アイデア帳に書いておくと添削で指摘されなくなります。書き方は次のどれでも構いません。

- アイデア帳で種類「読み方」を選び、語（足）と読み（アルファ）を入れる
- アイデア帳のメモ本文にルビの形で書く：`|足《アルファ》` または `足《アルファ》`
- アイデア帳のメモに1行で書く：`足＝アルファ`、`足：アルファ`、`足 → アルファ`
- 設定資料の項目の「読み」欄（人物名・地名・用語など）

登録した語に**登録と違う読み**のルビが付いていると、逆に「〇〇と読む設定です」と指摘します（ひらがな・カタカナの違いは同じ読みとみなします）。添削の指摘にある「読み方に登録」ボタンからも登録でき、登録済みの読み方は右の「資料」タブで一覧できます。

ルールごとのオン／オフ、一文の最大文字数などは「設定 → 添削ルール」で変えられます。台詞で意図的に使っている表現は「無視」できます。

### 設定資料
人物・場所・用語／アイテム・組織・生物・世界観ルール・年表をまとめて管理します。

- 人物：役割、年齢、一人称、口調、髪・瞳の色、性格、経歴、人物同士の関係と**呼び方**、**登場範囲**（初登場・退場／死亡した話）、自由項目、メモ
- 各項目の「登場回数」（どの話に何回出てくるか）
- 執筆画面の「資料」タブでは、**いま開いている話に出てくる**人物・場所・生物などを上に（多く出てくる順、回数つき）、出てこない項目をその下に並べます
- **出番表**：人物（場所・用語・組織・生物も）が、どの話に何回出てくるかを表で一覧。多く出ている話ほど色が濃く、マスを押すとその話を開きます。退場・死亡したあとや初登場より前に名前が出る話は赤く示し、「長く出てこない人物」「まだ本文に出てこない項目」も教えます。多く出ている順・初めて出た順・長く出ていない順に並べ替えられます
- 世界観ルール：世界観の説明・語り手・あらすじ、**通貨**、**単位**、**暦と時刻**、**文明の水準**、作中に存在しない言葉（**NGワード**）と言い換え、表記統一ルール、**世界の設定メモ**（下を参照）
- 設定資料を Markdown で書き出し
- **設定資料集を印刷（PDF）**：「↓」メニューから、設定資料を本のように読める形で印刷できます（表紙・人物・場所・用語・組織・生物（姿の図つき）・世界観ルール・年表。入れる章は選べます）。印刷画面で「PDFに保存」を選ぶとPDFになります
- **名前を考える**：人物・場所の一覧の「名前を考える」で、名前の候補を出します。和名（現代・時代もの）は読みつき、西洋風のカタカナ名、ファンタジーの造語（エルフ風・ドワーフ風・魔法風）、地名（和風・カタカナ）。気に入った名前はそのまま設定資料に足せます（和名は、名だけ・姓だけの呼び方も別名として登録するので、設定チェックにもそのまま使えます）

#### 生物（姿の図・骨格・大きさ比べ）
竜・魔獣・幻獣などを、分類・すみか・食べもの・寿命・強さ・大きさ・姿の特徴・能力・弱点・言い伝えと一緒に登録し、**横から見た姿の図**をその場で描きます（外部の画像生成は使わず、アプリの中で毎回作ります）。

- **大きさに合わせた図**：「全長」に「40m」「約四十メートル」「30〜40m」「旅客機ほど」「象の3倍」「バス2台分」のように書くと、その大きさの図になります。世界観ルールの単位（「五十歩」など）もそのまま使えます。高さや翼を広げた幅だけでも合わせられます
- **大きさ比べ**：人（1.7m）と、近い大きさのもの（りんご・猫・馬・象・バス・鯨・城の塔・旅客機・城）を自動で選んで同じ縮尺で並べ、全長・高さの寸法線と目盛りを入れます。比べるものは選び直せます
- **3つの表し方**：姿（色つきの模型の図）、**骨格**（背骨・肋骨・頭骨・四肢・翼の骨を暗い背景に）、**透かし**（体の輪郭の中に骨）
- **自然な体つき**：獣は尻の丸み・くびれた脇腹・深い胸・肩の盛り上がり（き甲）・付け根の太い首、脚はももや前腕の筋肉のふくらみと丸い足先で描きます。頭と首は継ぎ目の線なしにつながり、熊は足の裏をつけて歩く足と肩のこぶ、獅子は首から胸までおおう波打つたてがみ、鳥型の翼は雨おおいと風切り羽、甲虫・蜘蛛は脚で体を持ち上げた節のある脚で描きます
- **体の形のひな形**：竜（四本脚・翼）、飛竜、東洋の龍、大蛇・海蛇、恐竜（二本脚）、狼・犬、獅子・猫、熊、馬・鹿、天馬・一角獣、グリフォン、鳥・怪鳥、巨人・鬼（正面から）、ヒュドラ（多頭の竜）、ケルベロス（三つ首の犬）、八岐大蛇、鯨、大魚・鮫、大蟲（甲虫）、大蜘蛛、スライム。名前に「竜」「狼」「鬼」「ケルベロス」「八岐大蛇」などがあれば自動で近い形を選びます
- **頭の数**：四本脚・二本脚・蛇の形は、頭を1〜9つにできます（多い首は扇のように開き、奥の首は暗く描きます）
- **細かく変える**：首・尾・脚の長さ、体の太さ、頭・翼の大きさ、頭の数、角（後ろへ反る・巻き角・枝角・一本角・牛の角）、翼（膜・羽根、広げる・たたむ）、背のとげ・背びれ・たてがみ、尾の先、体と腹の色
- **体重と飛ぶことの目安**：図の体の大きさから体重を見積もり、翼の大きさに対して重すぎるときは「現実の生き物なら飛ぶのは難しい重さ」と教えます（理由づけの手がかりに）
- 図は **PNG・SVG で保存**できます。執筆画面の「資料」にも小さな図が出ます
- 生物を削除すると、地図に置いたその生物の絵もいっしょに消えます（確かめてから消します）
- **AI（任意）**：「説明から形を決める（AI）」で、姿の特徴などの文章から体の形・角・翼・色（大きさが書いてあれば全長も）を選びます

#### 世界観ルール（通貨・単位・暦・文明）
「この世界の決まり」を書いておくと、本文の中の“この世界にないもの”を見つけ、この世界の言い方に直す案を出します（執筆画面の「設定チェック」）。決めた項目だけをチェックします。上の項目ボタンで、それぞれの所へ移れます。

| 項目 | 決めること | 本文でのチェック（例） |
| --- | --- | --- |
| 通貨・物価 | 硬貨の名前と換算（ひな形：金貨・銀貨・銅貨、両・分・朱・文）、円での目安、物価の表 | 「千円」→「銅貨十枚」（円の目安を入れたとき）、「ドル」、設定にない「白金貨」 |
| 単位 | 長さ・重さ・量の単位と、現実でいうとどれくらいか（ひな形：歩・里・斤、尺・間・里・貫・升） | 「百メートル」→「約百三十歩」、「三千メートル」→「一里足らず」、「二キロ先」→「半里」、「十キロの荷物」→「約十七斤」 |
| 暦と時刻 | 年の数え方、月と曜日の名前、曜日や時計のあるなし、時刻の言い方 | 「西暦」→「王国暦」、「三月」→ 3番目の月の名前、「月曜日」、時計のない世界の「三時」「十分後」 |
| 文明の水準 | 時代の目安（中世風・近世風・蒸気の時代・和風）と、この世界にないもの（電気・自動車・銃・時計・写真・近代の素材・近代の医療・紙幣）、ほかにないもの | 「電話」→「伝令」、「拳銃」、「時計」（「砂時計」「日時計」は除く）、「写真」→「肖像画」 |
| 外来語 | 和風・時代もので、カタカナの外来語を控える（約120語） | 「ドア」→「戸」、「チャンス」→「好機」、「テーブル」→「卓」 |

- **造語のお金**：お金ごとに名前・読み・メモ（素材・見た目・発行元など）を書けます。「造語のお金を考える」で、「黒聖貨（こくせいか）＝ 白銀貨100枚 ＝ 赤銅貨10,000枚」のような、この世界だけのお金を高い順に3段の組み合わせで考えられます（漢字の造語・カタカナの造語）。決めたお金の読みはルビの登録になり、「黒星貨」のような似た名前や、カタカナの「ルークス／ルクス」のような表記ゆれも見つけます
- 通貨と単位には**換算の道具**があり、「金貨1枚は銅貨何枚か」「100mはこの世界で何歩か」をその場で確かめられます
- 「円形」「関東一円」「十分だ」「一時は」「三ヶ月」「センチメンタル」「インチキ」や、設定資料に登録した名前は指摘しません
- 単位・お金・暦の言葉は NGワードと同じく、台詞は常に、地の文は語り手に合わせてチェックします（神視点の語りで読者向けに「メートル」と書くのは指摘しません）。この世界にない物（電話など）は、地の文でも指摘します
- **世界の設定メモ**：魔法・特別な力、宗教・信仰、政治・身分、種族・民族、言葉・文字、地理・気候、暮らし・食べ物、法律・禁忌、呼び方・礼儀を、考えておくと良いことの例つきで書いておけます。書いた項目は AI の設定チェックで参照します
- **全話を調べる**：いまの世界観ルールで全話を調べ、合わない所を一覧にします（クリックでその場所へ）
- **まとめて直す**：執筆画面の「設定チェック」で、言い換えのある指摘が2つ以上あると「この世界の言い方にまとめて直す」が出ます。直す所を1つずつ確かめてから直せ、直す前の本文は版の履歴に残ります
- **辞書でも**：辞書で「銀貨3枚」と調べるとほかのお金での額と円の目安を、「歩」と調べると単位の大きさを、「100メートル」「千円」「電話」と調べるとこの世界での言い方を出します

### キャラ相関図
設定資料の人物と、その「関係」から相関図を自動で描きます（設定資料タブの「相関図」）。

- 人物をドラッグで配置、「自動配置」できれいに並べ直し、ホイール／ピンチで拡大縮小
- 「線をつなぐ」で人物から人物へドラッグすると関係を追加。線や文字をクリックで種類・呼び方を編集
- 関係の種類（家族・恋人・友人・師弟・主従・同僚・ライバル・敵対など）ごとに色と線の形が変わり、両方向の関係は2本の曲線で表示
- 「〇〇さん」などの**呼び方**も線の上に表示（台詞の呼び方チェックと共通のデータ）
- 退場・死亡した人物は点線の枠で表示。組織を表示して所属を線で結ぶこともできます
- PNG で書き出し

### 設定と違うときの添削（設定矛盾チェック）
設定資料と本文を照らし合わせ、食い違いを自動で検出します。

- **名前の表記ゆれ**：斎藤／斉藤 のような異体字、ヴァイス／バイス のようなカタカナの揺れ、アルセイド／アルセイト のような誤字候補
- **一人称**：台詞の話者を推定し（「〜」と太郎は言った／太郎は「〜」／太郎「〜」 などの形のほか、台詞だけの行なら次の行の「太郎は〜と言った」や前の行の主語から）、設定と違う一人称を検出。「彼女が」など名前でない主語が間にあるときは推定しません
- **呼び方**：「蓮くん」と呼ぶはずの人物が「蓮さん」と呼んでいる、などを検出
- **外見**：設定と違う髪の色・瞳の色の描写（染めた・変装などの文脈や「白い目で見る」などの慣用句は除外）
- **年齢**：設定と違う「〇歳」
- **生物の大きさ**：「全長十メートルの黒竜」のような描写が、設定資料の生物の全長・高さ・翼の幅と大きく違うとき（「十メートル先」のような距離は見ません。この世界の単位「五十歩」なども換算します）
- **登場範囲**：退場・死亡したはずの人物の発言、初登場前の発言
- **世界観NGワード**：中世風の世界の「メートル」など。台詞の中は常にチェックし、地の文は**語り手（視点）**に合わせます（下を参照）
- **世界観ルール**：通貨・単位・暦・文明の水準に合わない言葉を、この世界の言い方に換算して直す案を出します（上の「世界観ルール」を参照）
- 設定資料に**未登録の固有名詞の候補**を一覧にし、ワンクリックで登録

#### 語り手（視点）と世界観NGワード
地の文に「メートル」が出てきても、語り手が作品の外にいる**神視点**なら、読者向けの説明として問題ないことがあります。そこで「設定資料 → 世界観ルール → 語り手」で、作品の語り手を選べます。

| 語り手 | 台詞のNGワード | 地の文のNGワード |
| --- | --- | --- |
| 一人称（作中の人物が語る） | 指摘する | 指摘する |
| 三人称・一元視点（作中の人物に寄り添う） | 指摘する | 「参考」として控えめに指摘 |
| 三人称・神視点（作品の外から語る） | 指摘する | 指摘しない |
| 自動（標準） | 指摘する | 地の文に「僕は」「私の」などがよく出てくれば一人称、そうでなければ三人称として扱う |

- 話ごとに語り手が違うとき（幕間だけ別の人物の一人称、など）は、執筆画面の「設定チェック」タブで、その話だけ変えられます
- NGワードごとに「対象」も選べます：**台詞＋語り手しだい**（標準）／**台詞も地の文も**（「スマホ」のように、どんな語り手でも出てきてはいけない語）／**台詞だけ**
- AIの設定チェックにも、語り手の設定が伝わります

### AI（Claude）による添削・設定チェック・相談（任意）
Anthropic の APIキーを「設定 → AI」に入れると、Claude による次の機能が使えます。

- **AIで添削**：誤字・文法・表現・視点や時制の揺れなどを、講評つきで指摘（修正案はワンクリックで適用）
- **AIで設定チェック**：設定資料全体と原稿を照らし合わせ、口調・性格・能力など、ルールでは拾えない食い違いも指摘
- **AIに相談**：「この展開に無理はない？」「ラストのアイデアを3つ」など自由に相談
- **応募用のあらすじ**：設定資料の「世界観ルール」の「作品のあらすじ」で「本文からあらすじを作る（AI）」を押すと、全話の本文と設定資料から、新人賞の応募書類向けに**結末まで書いた**あらすじを400・800・1200・2000字から選んだ長さで作ります（前のあらすじは下に残します。字数も表示）

モデルは Claude Opus 5.5（標準）／Sonnet 5.5／Haiku 5.5 から選べます。利用料はAPIキーの持ち主に従量課金されます。APIキーはその端末のブラウザにだけ保存され、作品のバックアップには含まれません。AI機能を使ったときだけ、本文と設定資料が Anthropic の API に送信されます。

### アイデア帳
思いついたことをすぐメモ（Ctrl+Enter）。種類（アイデア・台詞・シーン・設定・伏線・タイトル案・資料・**読み方**）、タグ、色、ピン留め、検索。プロットボードや話のメモにも送れます。種類「読み方」のメモは、添削でルビを指摘しないための登録になります（上の「特殊な読み」を参照）。

- **伏線の管理**：種類「伏線」のメモには「張った話」「回収する話」「回収済み」を記録できます。「未回収の伏線」で絞り込めるほか、執筆画面の「資料」タブに、その話で張る・回収する伏線と、ほかの未回収の伏線が出ます（チェックで回収済みに）

### 投稿サイト用の書き出し
右上の「↓」→「投稿サイト用に書き出す」（または話の「…」メニュー）から、ルビ・傍点の書き方を投稿先に合わせて変換し、コピーまたは .txt で保存できます。

| 書き出し先 | ルビ | 傍点 | そのほか |
| --- | --- | --- | --- |
| 小説家になろう | `\|漢字《かんじ》` | ルビの「・」で代用 | 「漢字（かな）」が勝手にルビにならないよう「\|」を補う。10文字を超えるルビを知らせる |
| カクヨム | `\|漢字《かんじ》` | `《《傍点》》` | — |
| pixiv | `[[rb:漢字 > かんじ]]` | ルビの「・」で代用 | 話の題は `[chapter:題]`、話の区切りは `[newpage]` |
| ルビを（）書き | `漢字（かんじ）` | 記号を外す | メールなど |
| ルビなし | 外す | 外す | — |

あわせて、段落頭の字下げ（そのまま／地の文に付ける／外す）、段落の間に空行を入れる（Web向け）、半角の ! ? を全角に、話の題を入れる、を選べます。

### 電子書籍（EPUB）
右上の「↓」→「電子書籍（EPUB）で書き出す」で、Kindle・Apple Books・楽天Kobo・BOOTH などで読める EPUB 3 の本にします。

- 縦書き（右から左へめくる）／横書き
- ルビ・傍点・縦中横（!? や2桁の数字）、目次、扉（題と著者名）
- 全話、または1話だけ

### Word（.docx）で書き出す（応募書式）
右上の「↓」→「Word（.docx）で書き出す（応募書式）」で、新人賞などの応募でよく指定される書式に合わせた Word の文書にします。Word・Pages・Googleドキュメント・LibreOffice で開けます。

| 書式 | 内容 |
| --- | --- |
| A4横・縦書き 40字×34行 | よくある応募書式 |
| A4横・縦書き 40字×30行／42字×34行 | 〃 |
| A4横・縦書き 20字×20行 | 原稿用紙と同じ字数 |
| A4縦・横書き 40字×30行 | 横書きの応募 |
| 字数と行数を指定 | 縦書き・横書き、1行10〜60字・1枚5〜60行 |

- 用紙の向き・余白・文字の間隔を、指定の字数と行数がぴったり収まるように決めます（Word の「文字数と行数を指定」の設定）
- ルビは Word のルビ（ふりがな）として入ります。「（）で書く」「外す」も選べます。傍点は圏点、縦書きの「!?」や2桁の数字は縦中横に
- 1枚目に題と名前（扉）、話ごとに新しいページから、ページ番号、書体（明朝・ゴシック）を選べます。およその枚数も先に確かめられます

### 原稿用紙・応募書式で印刷
右上の「↓」→「原稿用紙・応募書式で印刷（PDF）」で、新人賞などに応募するときの書式に割り付けて印刷します（印刷の画面で「PDFに保存」を選ぶと PDF になります。用紙は A4 横）。

| 書式 | 内容 |
| --- | --- |
| 原稿用紙 | 20字×20行のマス目つき。真ん中に柱（折り目）のすき間 |
| A4横・40字×30行 | 応募でよくある書式（マス目なし） |
| A4横・42字×34行 | 〃 |
| 字数と行数を指定 | 1行10〜60字・1枚5〜60行、マス目の有無 |

- 原稿用紙の書き方に沿って割り付けます：題は4マス目から、名前は行の終わりを1マス空けて、句読点や閉じ括弧が行の頭に来るときは前の行の下にぶら下げ、開き括弧は行の終わりに置かない、半角の数字は2桁で1マス
- ルビは「外す（漢字だけ）」か「（）で書く」を選べます。題と名前、話の題、話ごとに新しい紙から、も選べます
- 印刷する前に、割り付けた結果の最初の2枚と枚数（400字詰め換算の目安も）を確かめられます

### プレビュー
読者にどう見えるかを確かめられます（執筆画面のツールバーや右上の本のボタン、書き出しメニューから）。

- **縦書き**：文庫本のようにページをめくって読めます。広い画面では見開き、スマートフォンでは1ページずつ。← → キー・クリック・スワイプでページ送り、最後のページの次は次の話へ

- 目次、文字の大きさ、明朝／ゴシック、配色（生成り・白・黒）
- ルビ・傍点・縦中横（!? や2桁の数字）に対応
- **印刷・PDF**：表示中の話、または全話を表紙つきで印刷。印刷画面で「PDFに保存」を選ぶと PDF になります

### 辞書
調べたいことを、書きながらすぐ調べられます。執筆画面の右の「辞書」タブ（本文で語を選んでから開くとその語を調べます）、またはどの画面からでも右上の辞書ボタンで開けます。

- **作品の中**：設定資料・登録した読み方・アイデア帳・本文での使用回数（クリックで該当箇所へ）
- **創作辞典**（オフライン）：言い換え・仕草（「見る」→ 眺める・凝視する・一瞥する…）、日本の伝統色（色見本つき）、天気・自然、時刻・暦、数え方（助数詞）、昔の単位・外国の単位。候補をクリックすると本文に入ります（選んでいる語と置き換え）

- **AIに聞く**：APIキーを設定していれば、Claude に意味・例文・言い換え・使うときの注意を聞けます

### 空想地図
Inkarnate や Wonderdraft のような「素材を置いて描く」ファンタジー地図エディタです。

- **世界地図**：「世界地図（いくつもの大陸）」を選ぶと、横長（2:1）の地図に4〜7つの大陸と島々を作ります。緯度に合わせた気候帯（赤道の密林・乾いた砂漠の帯・温帯の草原と森・針葉樹林・ツンドラ・雪原）、極地の氷、**経緯線**（赤道・回帰線・極圏つき）、地球規模の縮尺が自動で付きます。配色は地図帳が標準です
- **新しい地図**：世界地図・大陸・群島・ひとつの島・多島海・海岸線・内海のある大地・白紙から選び、シードを変えると別の地形に。山脈・丘・森・**川**・沖の波や船まで自動で配置でき、作ってすぐ「完成した地図」になります
  - 山は、陸のあちこちを走る細長い**山脈**の筋に沿って連なります（陸の真ん中がひとかたまりの山になりません）。山脈の間には平野や高原が広がり、尾根ほど大きな主峰、両わきには低い峰が並んで山並みに厚みが出ます。小さな島では海にはみ出さない大きさに
  - 山は銅版画のような描き方：細い輪郭線、光の当たる面には尾根のひだ、陰の面には斜面に沿った細い線。ときどき奥に低い峰が重なり、裾は地面になじむようにぼかします
  - 川は高い所から低い方へ流れ、支流は本流に合流し、河口で海に溶け込みます
  - **気候**（国・地方の地図）：温帯（四季のある国。標準）・寒い（針葉樹と雪）・暖かい（南国の密林とヤシ）・乾いた（荒れ地と砂漠）から選べ、地面の塗り分けと木の種類が変わります。地図の上（北）ほど少し寒くなります。世界地図は緯度で決まります
  - 草原には、ぽつんと立つ木のほか、草むら・茂みや、木が数本かたまった小さな林を散らします
  - 広い沖には、ときどき海竜・鯨・大ダコを1つ置きます（古地図の飾り）
  - **川・山脈・森の名前**（国の地図で町を置くとき）：長い川には流れに沿って「〇〇川」、山の連なりには連なりの向きに「〇〇山脈」、大きな森には真ん中の小さな空き地に「〇〇の森」と、仮の名前を付けます（ほかの文字や町の名前とは重ねません。あとで変えられます）
  - **町と道**（国の地図）：平らで川や海に近い所に王都・町・村・港を置き、山や水を避けてつなぎます。町と村のそばには、道にかからない所に畑を置きます。王都・港・町は2本線の「街道」で、村は「道」で結びます。地名は仮のカタカナで、あとから変えられます
  - **大陸と海の仮の名前**（世界地図）：大きな大陸に「〇〇大陸」、広い海に「〇〇海／〇〇洋」を付けます
- **地形ブラシ**：陸・海を描く、起伏（高く・低く・なだらかに）、地面の質感（草原・森の地面・砂漠・湿地・雪原・密林・荒れ地・岩場・農地・焦土）
- **素材（約60種）**：山・雪山・火山・滝・丘・岩、広葉樹・針葉樹・ヤシなどの木・オアシス、城・都市・町・村・塔・砦・神殿・港・灯台・風車・橋・市場・修道院・闘技場・鉱山・墓地、天守閣・五重塔・鳥居などの和風、遺跡・洞窟・環状列石・水晶・世界樹・竜の棲み処・古戦場、帆船・海竜・大ダコ・鯨・渦潮・波、**紋章（盾）・紋章の垂れ旗・旗**など。どれも配色（羊皮紙・地図帳・墨絵）に合わせて色が変わります。名前で**検索**でき、**最近使った素材**も並びます
- **物語の足どり**：地図の設定の「物語の足どり」を選ぶと、各話の本文に出てくる場所を、出てくる順に赤い点線の道すじでつなぎ、話の番号の札を付けます（往きと帰りは弧が反対側にふくらみ、矢印で向きを示します）。設定資料の「場所」とつないだ素材、または同じ名前の素材が対象で、話ごとの行き先は一覧でも確かめられ、押すとその場所へ移ります。凡例にも出ます
- **地名をまとめて設定資料に**：地図の設定の「地名の一覧」の「地名をまとめて設定資料に登録」で、まだ設定資料にない町・城・港の名前と、国・川・山脈・森・海などの文字を、種類つきで「場所」に登録します。国の中にある地名は、その国を「所在地」にします（町の絵は登録した項目とつながります）
- **設定資料の生物を地図に**：素材の「生物（設定資料）」に、設定資料の「生物」がその姿の図のまま並び、すみかなどに置けます。地図の絵柄（太い輪郭線・地図の紙の色になじむ色）で描き、設定資料で形や色を変えると地図の絵も変わります。選ぶとその生物の設定が出て、設定資料からも「〇〇の地図で表示」で置いた所へ移れます
- **紋章・旗**：盾・垂れ旗・旗の3種に、星・縦二分・横帯・山形・十字・斜め十字・斜め帯・四分割・王冠・塔・太陽・三日月の12の図柄。選ぶと図柄と**色**を変えられます（金と銀の飾りは、地の色に合わせて見分けやすい方を使います）
- **選んだ素材・文字の取っ手**：角の四角をドラッグで大きさ、上の丸で向き（Shift で15°刻み）。**最前面へ／最背面へ**で重なりの順も変えられます
- **散布ブラシ**：なぞるだけで森（広葉樹・針葉樹・混交林・雪・密林）や山脈・丘陵・岩場・砂丘・湿地をまとめて描画
- **山・森を置き直す**：地形を描き変えたあと、山・丘や森を今の地形に合わせて自動で置き直せます（町や文字はそのまま）
- **道・川**：フリーハンドまたはクリックで川・街道・道・小道・鉄道・国境・航路。道が川を渡る所には、道の向きに合わせた**橋**（板の床・欄干・柱）が自動で架かります（自分で描いた道でも）。道は古地図の描き方で、街道は細い2本線、道は破線、小道は点線。淡い縁取りつきで山や森の上に描くので（町の絵の下を通ります）、森の中でも見失いません。縮小して見ているときは少し太く表示します。川は海や湖に入るところで水面に溶け込みます。新しく描いた川は、描いた向きに関係なく、低い方（下流）ほど太くなります。**領域**で国や領地を塗り分け
- **文字**：地名・海の名前などを、書体・大きさ・回転・縦書き・**曲線に沿って**配置。地名の大きさは地図の広さに合わせて決まり、「地名の大きさ」で調整できます
- **地名を重ねない**：町や城の名前は、ほかの名前・置いた文字・町の絵と重ならず、地図の外にはみ出さない向き（下・右・左・上）を自動で選びます。首都・城・都市の名前が優先です。素材ごとに「名前の位置」を決めればその向きのまま（地図の設定で切ることもできます）
- 配色（**冒険の地図（深緑の海）**・**水彩の古地図**・羊皮紙・地図帳・墨絵・夜）、陰影・波紋・マス目（四角・六角・経緯線）・縮尺・題名（帯／額）・枠（シンプル／古地図風）・紙の質感・極地の氷・**方位線**
  - 冒険の地図：深い青緑の海に、海岸に沿った何本もの波線（海岸からの正確な距離で引くので、島のまわりでも等間隔）。陸はオリーブと土の色、山は土色の岩山、森は濃い緑、道は白い点線、海の名前は淡い色。新しい地図はこの配色が標準です
  - 水彩の古地図：にじんだ青緑の海と黄みの陸、灰色の山並み。世界地図の標準です
  - 方位線：方位記号から32方位に細い線をのばし、地図の中心に目盛りつきの大きな円。陸の上と、地図の枠の外には描きません
- 質感：海は岸から沖へなめらかに深くなり、沖には版画のような細い波の模様。陸は水彩のようなゆるやかな色むらと、海岸の内側のわずかな陰。冒険の地図・水彩の古地図では、地面を手で塗ったように（乾いた草地と緑の濃い草地のむら・筆の跡・拡大したときの細かな草のつぶ）。地面の種類の境目は曲線でなじみ、湿地はふちのある水たまりと古地図の横線で描きます。紙の質感は向きのない細かな目と繊維。大きく拡大すると、見えている所の地形を細かく描き直すので、ぼやけたり角ばったりしません
- **国に分ける**：地図の設定の「国に分ける」で、陸を山の尾根や大きな川を境にしながら国に分け、隣と違う色の塗り・国境・国名・首都の印を付けます。国の数は自動か2〜20か国から選べ、「別の分け方」で何度でも作り直せます（自分で描いた領域や文字はそのまま）。世界地図は、最初から国に分けて作ることもできます
  - 国名は、大きい国から順に、ほかの国名や地図にある文字と重ならない所に置きます（入りきらない小さな国は少し小さな文字に）。山の絵の上はなるべく避け、文字の真下に根元がある山・木はどけて読みやすくします
  - 国の塗りは海岸線で切り抜くので、海にはみ出しません（自分で描いた領域も「陸だけを塗る」を選べます）
  - 冒険の地図・水彩の古地図では、国の中は塗らずに、国境の内側を外から内へうすれていく色の帯で示します（地形の絵がそのまま見えます）。地図の設定の「国・領域の塗り方」で、どの配色でも「中まで塗る／境の内側だけ」を選べます
  - 「国名の横に紋章の旗を置く」を選ぶと、国名の横に国の色の垂れ旗を置きます（図柄はばらばら。選んで変えられます）
  - 国を選ぶと、名前（地図の国名もいっしょに変わります）・色と、**面積**（日本の何倍か）を確かめられます
- **距離を測る**（M）：クリックで点を打つか、指やマウスで道をなぞると、道のりと**旅の日数**（徒歩・馬・馬車や隊商・帆船）を表示します。通る地形（道・平地・森・丘・山・湿地など・海）の割合も出し、山越えや道のない森は時間がかかるものとして計算します。世界地図では、球の上の距離（大圏距離）で測ります。旅の速さは変えられ、測った経路はそのまま「道」にできます
  - 道・街道を選ぶと、その長さと旅の日数も表示します
- **レイヤー**：地形・領域・道・素材・文字・装飾ごとに表示／非表示、ロック
- 素材や文字を設定資料の「場所」とつなげ、設定資料から地図を開ける
- **範囲を詳しい地図に**：地図の一部をドラッグで囲むと、その範囲を拡大した新しい地図を作ります（世界地図 → 国 → 地方）。地形はただ引き伸ばすのではなく、海岸線や起伏を細かく描き足し、山・森・小さな川も置き直します。町・道・国境・地名は位置を合わせて引き継ぎ、縮尺も自動で直します。新しい地図から元の地図へ戻れます
- **凡例**：地図で使っている町・建物・道・国などから、凡例を自動で作ります（四隅から位置を選べます）
- 元に戻す／やり直す、複数選択・コピー・貼り付け
- **画像で書き出し**：等倍〜4倍、印刷用の **A4・A3（300dpi）**、PNG／JPEG（JPEG は白い下地で軽く）
- 大きな地図でも、拡大・移動はなめらか（表示だけが変わるときは、描き上がった地図を使い回します）
- スマートフォンでは道具と設定が下から出るシートになり、2本指で移動・拡大縮小できます
- キー操作の一覧は「?」キーか、上の ⓘ ボタンで表示。主なキー：V 選択・H 移動・B 陸・N 海・R 起伏・G 地面・S 素材・F 散布・X 消す・L 道・A 領域・T 文字・M 距離、[ ] で大きさ、Q／E で回転

## アプリとして使う（ホーム画面・デスクトップから開く）
綴りは「PWA（インストールできるWebアプリ）」に対応しています。https のサイトで公開すると、次のように**アプリとして入れられ、オフラインでも使えます**。

1. このリポジトリを GitHub Pages などで公開する（Settings → Pages → 公開するブランチとフォルダ（ルート）を選ぶ）
2. 公開された URL を開き、
   - **パソコン（Chrome・Edge）**：アドレスバーの「インストール」ボタン、またはアプリ内の「アプリとして入れる」
   - **Android（Chrome）**：メニューの「アプリをインストール」、またはアプリ内の「アプリとして入れる」
   - **iPhone・iPad（Safari）**：共有ボタン →「ホーム画面に追加」
3. 入れたあとは、ホーム画面やデスクトップのアイコンから開けます。一度開けば、電波のない所でも執筆・設定資料・地図などが使えます（AI と辞書のネット検索だけは通信が必要です）

- 作品データは、入れたアプリでもブラウザと同じく端末の中に保存されます。ブラウザで書いた作品をアプリに移すときは、バックアップを書き出して読み込んでください
- 新しい版を公開すると、次に開いたときに自動で取り込まれます
- 1ファイル版（`dist/tsuzuri.html` を直接開く使い方）は、ブラウザの制限でアプリとしては入れられません

### App Store・Google Play で配るには
今の作りのまま「アプリの包み」をかぶせれば、ストア向けのアプリにもできます（このリポジトリでは、まだ用意していません）。

| 配り先 | 方法 | 必要なもの |
| --- | --- | --- |
| iPhone・iPad（App Store） | Capacitor などで包む | Mac と Xcode、Apple Developer Program（年額）、審査 |
| Android（Google Play） | Capacitor、または TWA（PWA をそのまま包む） | Google Play の開発者登録（初回のみ）、署名、審査 |
| Windows・Mac のアプリ | Tauri や Electron で包む | 各OS向けの署名（配布の警告を出さないため） |

ストア版にするときは、作品データの保存先（アプリ内の保存領域）と、AI の APIキーの扱い（各自のキーを入れてもらう今の形）を、そのまま使えます。

## データについて
- 保存先：ブラウザの IndexedDB（使えない環境では localStorage）。入力すると自動保存されます
- バックアップ：作品ごと、またはすべての作品を `.tsuzuri.json` で書き出し・読み込み
- 3,000字以上ある作品を一度もバックアップしていないときや、前回のバックアップから7日以上たって書き足したときは、作品一覧の上でお知らせします
- 起動時に、ブラウザへ「容量が少なくなっても作品データを消さないで」と頼みます（ブラウザによっては確認が出ます）
- 別の端末に移すときは、バックアップを書き出して、移した先で読み込んでください

## セキュリティ
- **外へ送るもの**：AI機能を使ったときの本文・設定資料（Anthropic の API へ）と、辞書のネット検索で調べた言葉（Wikipedia／ウィクショナリーへ）だけです。それ以外に作品データを送ることや、解析・広告の通信はありません
- **文字の形（フォント）**：見やすい日本語の書体を Google Fonts から読み込みます。作品の中身は送りませんが、Google には端末の IP アドレスと、書体を読み込んだことが伝わります（どのページから来たかは送りません）。つながらないときは端末の書体で表示します
- **CSP（コンテンツ セキュリティ ポリシー）**：Web で公開している版（GitHub Pages など）は、**アプリ自身のスクリプトだけ**を読み込めます。AI に使う Anthropic 公式 SDK（1.7.0）も、npm の公式パッケージから1つのファイルにまとめてアプリに同梱しているので（`js/vendor/anthropic-sdk.js`、ライセンスは `js/vendor/THIRD_PARTY_LICENSES.txt`）、外部のサイトからスクリプトを読み込みません。1ファイル版は、埋め込んだスクリプトの中身のハッシュ（sha256）で許可し、AI の SDK だけは同じ版を CDN から読み込みます（file:// ではファイルから読み込めないため）。通信先も Anthropic の API・Wikipedia・ウィクショナリーなどに限っています
- **ほかのサイトへの埋め込み**：ほかのサイトの中（iframe）で開かれたときは、作品を開かずに注意を出します（だまして操作させる手口を防ぐため。GitHub Pages では、埋め込みを禁じる HTTP ヘッダーを付けられないので、アプリ側で防いでいます）
- **細工したファイル**：とても長い行や閉じない記号を含むテキスト・バックアップを読み込んでも、固まらないようにしています
- **作品データの読み込み**：バックアップ（.json）は、`__proto__` などの危ないキーを取り除き、文字・数・色・ID の形を確かめてから取り込みます。作品の中に HTML やスクリプトが書かれていても、文字として表示するだけで実行しません
- **ネット辞書**：返ってきた URL は決まったサイトの https だけを使い、HTML は文字だけを取り出します
- **APIキー**：この端末のブラウザにだけ保存し、バックアップには含めません。共用の端末では「このタブを閉じるまで」を選べます（設定 → AI）
- 外部サイトへのリンクは `noopener noreferrer` で開き、リファラー（どのページから来たか）も送りません

## 開発者向け

ビルド不要の HTML / CSS / JavaScript です（依存パッケージなし。AI の SDK だけは `js/vendor/` に同梱）。

```
index.html          画面の枠
css/app.css         デザイン（ライト／ダーク／セピア）
js/textstats.js     文・会話文の解析、ルビ、文字数などの統計
js/readings.js      読み方（ルビ）の登録の集約
js/proofread.js     添削ルール
js/consistency.js   設定矛盾チェック（話者推定を含む）
js/dictdata.js      創作辞典のデータ（オフライン）
js/publish.js       投稿サイト用の書き出し（ルビ・傍点の変換）
js/mapengine.js     地図の地形生成・描画
js/mapassets.js     地図の素材（ベクターで描画）
js/creature.js      生物の図（体の形・骨格・大きさ比べを SVG で描く）
js/ai.js            Claude API 連携（公式 SDK をブラウザで読み込み）
js/views/*.js       各画面（執筆・設定資料・相関図・アイデア／プロット・地図・プレビュー・辞書）
tools/build.mjs     1ファイル版 dist/tsuzuri.html と、オフライン用の sw.js の作成
manifest.webmanifest, icons/, sw.js   アプリ（PWA）として入れるためのファイル（sw.js は build で作り直す）
tests/              テスト
```

```
npm test            # 添削・設定チェック・語り手・読み方・地図データ・辞書・投稿用書き出しのテスト（Node.js のみで実行）
npm run build       # dist/tsuzuri.html を作り直す
npm run serve       # http://localhost:8765 で起動
npm run e2e         # ブラウザでの動作確認（Playwright が必要。先に serve を起動）
node tests/e2e-ai-mock.js   # AI機能の結合テスト（APIキー不要）
node tests/e2e-sweep.js     # 全画面を巡回し、null などの表示崩れがないか確認
node tests/e2e-security.js  # CSP・細工したデータの読み込み・ネット辞書の安全確認（先に npm run build）
node tests/e2e-pwa.js       # アプリ（PWA）として入れられるか・オフラインで使えるか
```
