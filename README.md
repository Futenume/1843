# 綴り（つづり）— 小説執筆スタジオ

小説を書くことだけに特化した執筆アプリです。原稿・添削・設定資料・設定矛盾チェック・アイデア帳・プロット・空想地図を、作品ごとにひとつにまとめて管理できます。

- インストール不要。ブラウザだけで動きます（パソコン・スマートフォン対応）
- データはお使いの端末のブラウザ内に保存され、外部には送信されません（AI機能を使うときだけ、本文がAIに送られます）
- 添削と設定矛盾チェックは、AIなしでもその場で自動的に行われます

## 使い始める

いちばん簡単なのは、1ファイル版を使う方法です。

1. [`dist/tsuzuri.html`](dist/tsuzuri.html) をダウンロードする
2. ダブルクリックしてブラウザ（Chrome・Edge・Safari・Firefox）で開く
3. 「サンプル作品を開く」で、各機能の動きを確認できます

そのほかの方法：

- **GitHub Pages で公開する**：リポジトリの Settings → Pages で公開するブランチ（例：`main`）を選ぶと、どの端末からでも URL で開けます（データは端末ごとに別々に保存されます）
- **手元のサーバーで動かす**：リポジトリ直下で `python3 -m http.server 8765` を実行し、`http://localhost:8765` を開く

> データはブラウザに保存されるため、ブラウザの閲覧データを消すと作品も消えます。右上の「↓」ボタンや「設定 → データ」から、定期的にバックアップ（.json）を書き出してください。

## できること

### 執筆
- 話（章）の追加・並べ替え（ドラッグ）・複製・削除
- 文字数（空白除く）、400字詰め原稿用紙換算、今日書いた文字数と1日の目標
- 縦書きプレビュー（ルビ・傍点・縦中横に対応）
- ルビ `|漢字《かんじ》`、傍点 `《《強調》》`、「」『』……―― の入力ボタン
- 検索・置換（この話だけ／全話）
- 版の保存と履歴（大きく直す前に保存しておけば、いつでも戻せます。話の切り替え時にも自動保存）
- テキスト（.txt）での書き出し
- 統計：会話文の割合、漢字の割合、平均の文の長さ、読了目安、日ごとの執筆量

### 添削（AIなし・自動）
本文を書くと、その場で次の点をチェックし、該当箇所に波線を引きます。指摘をクリックすると本文の該当箇所へ移動し、提案があればワンクリックで直せます。

| 分類 | 内容 |
| --- | --- |
| 誤字 | 「完壁」「絶対絶命」などのよくある誤字、「、、」「をを」などの重複 |
| 語法 | 慣用句の誤用（的を得る・汚名挽回など）、重言（頭痛が痛い・違和感を感じるなど）、ら抜き言葉、地の文のい抜き言葉 |
| 記号 | 括弧の閉じ忘れ、閉じ括弧前の句点（〜。」）、三点リーダー・ダッシュの作法、！？の後の全角スペース、半角カナ・半角記号 |
| 体裁 | 段落頭の字下げ（作品全体の書き方に合わせて判定） |
| 読みやすさ | 長すぎる文、読点の多い文、同じ文末の連続（〜た。〜た。〜た。）、接続詞の連続、「の」の連続 |
| 表記 | 表記ゆれ（できる／出来る、子ども／子供 など約50語。作品全体で多い方に揃える提案）、設定資料の「表記統一ルール」 |

ルールごとのオン／オフ、一文の最大文字数などは「設定 → 添削ルール」で変えられます。台詞で意図的に使っている表現は「無視」できます。

### 設定資料
人物・場所・用語／アイテム・組織・世界観ルール・年表をまとめて管理します。

- 人物：役割、年齢、一人称、口調、髪・瞳の色、性格、経歴、人物同士の関係と**呼び方**、**登場範囲**（初登場・退場／死亡した話）、自由項目、メモ
- 各項目の「登場回数」（どの話に何回出てくるか）
- 世界観ルール：作中に存在しない言葉（**NGワード**）と言い換え、表記統一ルール、世界観の説明、あらすじ
- 設定資料を Markdown で書き出し

### 設定と違うときの添削（設定矛盾チェック）
設定資料と本文を照らし合わせ、食い違いを自動で検出します。

- **名前の表記ゆれ**：斎藤／斉藤 のような異体字、ヴァイス／バイス のようなカタカナの揺れ、アルセイド／アルセイト のような誤字候補
- **一人称**：台詞の話者を推定し（「〜」と太郎は言った／太郎は「〜」／太郎「〜」 などの形から）、設定と違う一人称を検出
- **呼び方**：「蓮くん」と呼ぶはずの人物が「蓮さん」と呼んでいる、などを検出
- **外見**：設定と違う髪の色・瞳の色の描写（染めた・変装などの文脈や「白い目で見る」などの慣用句は除外）
- **年齢**：設定と違う「〇歳」
- **登場範囲**：退場・死亡したはずの人物の発言、初登場前の発言
- **世界観NGワード**：中世風の世界の「メートル」など
- 設定資料に**未登録の固有名詞の候補**を一覧にし、ワンクリックで登録

### AI（Claude）による添削・設定チェック・相談（任意）
Anthropic の APIキーを「設定 → AI」に入れると、Claude による次の機能が使えます。

- **AIで添削**：誤字・文法・表現・視点や時制の揺れなどを、講評つきで指摘（修正案はワンクリックで適用）
- **AIで設定チェック**：設定資料全体と原稿を照らし合わせ、口調・性格・能力など、ルールでは拾えない食い違いも指摘
- **AIに相談**：「この展開に無理はない？」「ラストのアイデアを3つ」など自由に相談

モデルは Claude Opus 5.5（標準）／Sonnet 5.5／Haiku 5.5 から選べます。利用料はAPIキーの持ち主に従量課金されます。APIキーはその端末のブラウザにだけ保存され、作品のバックアップには含まれません。AI機能を使ったときだけ、本文と設定資料が Anthropic の API に送信されます。

### アイデア帳
思いついたことをすぐメモ（Ctrl+Enter）。種類（アイデア・台詞・シーン・設定・伏線・タイトル案・資料）、タグ、色、ピン留め、検索。プロットボードや話のメモにも送れます。

### プロットボード
場面・出来事をカードにして起承転結（列は自由に追加・改名）に並べます。ドラッグで移動、話との紐づけ、カードから話を作成。

### 空想地図
- 大陸・群島・島・海岸線・内海などの地形を**自動生成**（シードを変えると別の地形に）
- ブラシで**陸・海を描く／山を盛る／削る／均す**、森・砂漠・湿地・雪原などの**植生**を塗る
- 起伏の陰影・海岸線・等深線・山や森の記号を自動で描画（配色：羊皮紙・地図帳・墨絵）
- **川・街道・道・小道・鉄道・国境**の線、国や領地の**領域**
- 首都・都市・町・村・城・砦・港・神殿・遺跡・洞窟・塔・山頂、駅・学校・病院・神社・店・家・公園などの**地点**（現代の街の空想地図にも）
- 地名・海の名前などの**文字**（大きさ・回転・縦書き）、方位記号・縮尺・題名
- 地点を設定資料の「場所」とつなげ、設定資料から地図を開ける
- 元に戻す／やり直す、**PNG で書き出し**
- 操作：ホイール／ピンチで拡大縮小、スペース＋ドラッグで移動、キーで道具の切り替え（V 選択・B 陸・N 海・R 山・L 線・M 地点・T 文字、[ ] でブラシの大きさ）

## データについて
- 保存先：ブラウザの IndexedDB（使えない環境では localStorage）。入力すると自動保存されます
- バックアップ：作品ごと、またはすべての作品を `.tsuzuri.json` で書き出し・読み込み
- 別の端末に移すときは、バックアップを書き出して、移した先で読み込んでください

## 開発者向け

ビルド不要の HTML / CSS / JavaScript（依存パッケージなし）です。

```
index.html          画面の枠
css/app.css         デザイン（ライト／ダーク／セピア）
js/textstats.js     文・会話文の解析、ルビ、文字数などの統計
js/proofread.js     添削ルール
js/consistency.js   設定矛盾チェック（話者推定を含む）
js/mapengine.js     地図の地形生成・描画
js/ai.js            Claude API 連携（公式 SDK をブラウザで読み込み）
js/views/*.js       各画面（執筆・設定資料・アイデア／プロット・地図）
tools/build.mjs     1ファイル版 dist/tsuzuri.html の作成
tests/              テスト
```

```
npm test            # 添削・設定チェックのテスト（Node.js のみで実行）
npm run build       # dist/tsuzuri.html を作り直す
npm run serve       # http://localhost:8765 で起動
npm run e2e         # ブラウザでの動作確認（Playwright が必要。先に serve を起動）
node tests/e2e-ai-mock.js   # AI機能の結合テスト（APIキー不要）
```
